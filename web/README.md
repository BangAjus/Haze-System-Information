# Haze web dashboard

Placeholder until phase 4 (weeks 5–9). Design comes first: research and wireframes, then hi-fi, then code.

Planned stack: Next.js (App Router), TypeScript, TanStack Query, shadcn/ui, ECharts, MapLibre GL.
The typed API client is generated from the FastAPI OpenAPI spec (`http://localhost:8000/openapi.json`).

MVP pages: Overview, Pipeline runs, Data quality, Asset freshness, World map, City explorer.
Later: Model performance, Compare and rankings, Manual run.

See section 08 of [the plan](../docs/haze-plan.html).
