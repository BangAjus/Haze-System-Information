# Haze iOS app

Placeholder until phase 5 (weeks 8–12). Start with 3–5 user interviews, then flows, then hi-fi design, then SwiftUI.

Planned stack: SwiftUI, Swift Charts, SwiftData (offline cache), WidgetKit, CoreLocation, APNs.
Create the Xcode project here as `Haze.xcodeproj`.

MVP: Today, Tomorrow, Search and saved cities, City detail, Onboarding.
Later: Alerts, Widgets, Health guidance, Offline.

Always show how old the data is, and the OpenWeather / Kaggle attribution (CC BY 4.0).
See section 08 of [the plan](../docs/haze-plan.html).
